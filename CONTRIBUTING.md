# Contributing to Cartulary

Thanks for your interest! Bug reports, ideas, and pull requests are all welcome.

## Reporting bugs and suggesting features

Use the [issue templates](https://github.com/chris-3345/cartulary/issues/new/choose):

- **Bug report:** something is broken :0
- **Feature request:** an idea or improvement
- **Licensing issue:** a dependency, font, or asset is missing from the credits or shown with the wrong license (maintainers of crates we use are especially welcome here)

## Before you start on a pull request

For anything bigger than a small fix, **please open an issue first**

Note that Cartulary is **offline only.** It has no online features for now: no accounts, sync, telemetry, or game databases. PRs that add network features probably won't be accepted until I figure out how I want to do it since I don't have servers.

## Development setup

You'll need a recent stable [Rust toolchain](https://rustup.rs).

```sh
git clone https://github.com/chris-3345/cartulary
cd cartulary
cargo run
```

Before opening a PR, please run:

```sh
cargo fmt
cargo clippy
```

to make sure there are no new warnings. Some code only exists on certain platforms (look for `#[cfg(target_os = ...)]`), so a warning about something being "unused" could just mean it's only used on another OS; don't delete those

## Project layout

| File | What's in it |
|---|---|
| `src/main.rs` | App setup, `update`, and `view` |
| `src/ui.rs` | Page and widget builders (sidebar, Library, Create, Details) |
| `src/message.rs` | `Message`, `AppState`, `EntryDraft`, `FieldEdit` |
| `src/game.rs` | `GameEntry` and its types (`Status`, `Platform`, `Store`, `Rating`) |
| `src/storage.rs` | Loading and saving `library.json` |
| `src/constants.rs` | Fonts, wordmark, credits text, app ID |

## Be careful
<small>(otherwise people will open a ton of issues)</small>

### The save format

People's libraries are stored in `library.json`, and breaking it means goodbye data.

- **Adding** a variant to `Status`, `Platform`, or `Store` is safe. Remember to add it to that enum's `ALL` list too or it won't appear in the dropdowns (nothing enforces this :P).
- **Renaming or removing** a variant, or renaming/removing a field on `GameEntry`, **breaks existing saves.** If a change like this is needed, it must bump `FORMAT_VERSION` in `storage.rs` and include a migration from the old format (which I haven't decided how to do yet). Please discuss it in an issue first.
- Never save after a failed load. If a library can't be read, the app moves it aside and exits instead of overwriting it.

### Dependencies and licenses

Every dependency's license notice is bundled into the app via `CREDITS.txt`, which is generated by [cargo-about](https://github.com/EmbarkStudios/cargo-about). If your PR adds or updates a dependency:

1. Check its license is in the `accepted` list in `about.toml`. If it's not then mention it in the PR.
2. Regenerate the credits:
   ```sh
   cargo install cargo-about --locked
   cargo about generate about.hbs -o CREDITS.txt
   ```
3. Commit the updated `CREDITS.txt` with your change
